# 接口契约文档(API Contract)使用指南

> 这是**人手写**的接口契约文档,与 FastAPI 自动生成的 `/docs`(Swagger UI)互为补充。

## 与 Swagger UI 的关系

| 维度 | Markdown 契约(本文) | Swagger UI(/docs) |
|---|---|---|
| 字段类型 / 必填 | ✅ | ✅ |
| 字段业务含义 | ✅ | ❌ |
| 业务规则(校验逻辑) | ✅ | ❌ |
| 错误码 + 用户文案 | ✅ | ⚠️ 部分 |
| 调用示例 | ✅ | ❌ |
| 字段变更历史 | ✅ | ❌ |
| 现场调试 | ❌ | ✅ |

**结论**:**主用本 Markdown 文档**,Swagger 仅做调试辅助。

## 文档维护规则

- 每次后端新增 / 修改 / 删除端点,**同步更新本文件**
- 字段类型 / 必填变更 → 改对应端点
- 错误码新增 → 改 `7. 错误码清单`
- 任何接口变更 → 同步追加 `api-changelog.md`
