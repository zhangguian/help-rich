# v0.5 Roadmap · 小白看懂股市 · 改造计划(修订版)

**计划日期**:2026-08-03 · **定位延续**:买股看股辅助工具(小白向)
**核心目标**:把「看不懂」翻译成「看得懂」——看懂单只股票(K线/位置/信号)、看懂行业与大盘走势,降低瞎投资冲动。

---

## 一、修订要点(相对初版 v0.5-roadmap)

1. **验收硬指标化**:M1.2 补 P20/P80 分位阈值与止损公式;M1.3 补胜率统计口径。
2. **结构拆分**:原 M2.4 拆为 M2.4(热力图实装,纯前端)与 M2.5(情绪扩展,后端新接口),可并行推进。
3. **新增章节**:§六 里程碑依赖与工时预估;§七 交互体验规范。
4. **风险补全**:板块K线合成性能评估与缓存持久化决策、分时轮询指数退避、ORM 迁移兼容性。
5. **决策扩展**:新增 v0.5-5(板块缓存纯内存)、v0.5-6(M2.4 拆分并行)。

---

## 二、背景与约束

v0.4 已具备:四区工作台、K线智能分析(12 项指标 + 机械信号 + AI 白话解读)、大盘盯盘(指数/sparkline/涨跌分布/主力净流入)、板块资金、快讯、截图导入、AI 问答。

v0.5 聚焦小白最痛的三个「看不懂」:
1. 看不懂**个股K线和买卖位置** → 要直接结论 + 历史胜率背书
2. 看不懂**行业走势**(今天涨的是大盘还是我的行业) → 行业归属 + 板块K线 + 三线叠加
3. 看不懂**术语和方法** → 新手速看 + 持仓风险轻提示

用户三处拍板约束(决策记录见 §五):**行业三线不砍 · 北向资金砍掉 · 分时优先落地**。另确认:批量分时端点不入 v0.5;连板高度视探活结果决定。

## 四、里程碑任务

### M1 · 看懂单只股票

| 任务 | 内容 | 验收 |
|---|---|---|
| M1.1 分时图 | 后端保留 HH:MM + `trade_date` date→DateTime(alembic 迁移)+ 新端点 `GET /api/kline/{code}/intraday`(当日分钟线 + 均价线);前端周期组补「分时」入口 | `test_kline_intraday` 通过;盘中可取一条分时曲线;前端 build 通过 |
| M1.2 买卖位置参考卡 | AnalysisPanel 顶部强化:「高位/中位/低位风险带 + 参考支撑 + 建议止损价 + 一句白话」(全部基于现有 position/liar/通道指标,纯代码计算,不烧 LLM) | 任意股票打开即有白话评级;风险带阈值见下方说明 |
| M1.3 信号历史胜率 | 新增 `signal_winrate.py`:对当前 signal 在历史 120 根回检,返回 `{count, up5, up20}`;前端信号卡旁展示「该形态历史出现 N 次,5 日后上涨 M 次」 | `test_ta_signal_winrate` 通过;口径见下方说明 |

**M1.2 风险带阈值说明**(过去 120 个交易日收盘价分位数,纯代码计算):

| 级别 | 定义 | 参考展示 |
|---|---|---|
| 高位 | 当前价 ≥ P80 分位 | 「当前处于近 120 日高位区间,追涨风险偏高」 |
| 中位 | P20 ≤ 当前价 < P80 | 「当前处于近 120 日中位区间,可观察信号」 |
| 低位 | 当前价 < P20 | 「当前处于近 120 日低位区间,注意是否趋势下行」 |

- 参考支撑 = 近 20 日最低收盘价 × 0.98(留 2% 缓冲)
- 建议止损价 = 参考支撑 × 0.97
- 阈值参数集中写在 `config.py` 常量区,便于调参。

**M1.3 胜率统计口径补充说明**:

- 回检窗口:当前信号出现日往前 120 根日K,遍历其中**所有**产生相同 signal 的交易日为样本。
- 「5 日后上涨」= 信号出现日收盘价 < 该日后第 5 个交易日收盘价;`up20` 同理取第 20 个交易日。
- 120 根内同形态出现次数 < 3 → 前端展示「样本不足,仅供参考」,不展示百分比。

**M2.3 归一化与对齐规则**:

- **归一化基准**:以三条线各自**首个共同交易日**收盘价为基准(=100),后续按 `(close/基准价)×100`,右轴显示相对涨跌幅百分比。
- **时间对齐**:取三条线交易日**交集**,缺失日不做前向填充,保证对比公平。
- **数据源约束**:个股和指数走新浪直连;板块走 M2.2 合成曲线。行业归属未命中(兜底三级)→ 第三条线显示「行业数据暂不可用」空态,不影响前两条。

**M2.5 情绪指标优先级**:

| 优先级 | 指标 | 数据来源 | 说明 |
|---|---|---|---|
| P0 | 两市成交额 N 日趋势 | 复用 market_overview_service | 已有估算逻辑,加 5 日 sparkline |
| P0 | 涨停/跌停家数 | 新浪行情统计 | 探活后确认 |

## 七、交互体验规范

### 三线叠加(M2.3)

- 三条线配色固定:个股 = 蓝 `#3B82F6`、大盘 = 橙 `#F59E0B`、行业 = 紫 `#8B5CF6`;图例固定在主图左上角。
- 图例可点击切换显隐(默认全显),点击后对应线条淡出至 20% 透明度。
- 行业线不可用 → 图例项置灰并显示 `?` tooltip 说明原因。

### 分时图(M1.1)

- 十字光标联动:show 三列 `{时间, 价格, 均价}`。
- 昨收价虚线标注于 Y 轴,高于昨收区域填充淡红、低于填充淡绿。
- 分时曲线右端固定显示当前最新价数字标签。

### 新手速看卡(M3.1)

- 5 条内容纵向排列,每条固定 2 行高;窄屏(<768px)从右侧面板降级为底部横向滚动条,避免挤压 K 线区。
- `?` tooltip 点击触发(非 hover),移动端友好;内容含一个基于当前股票数据的实际例子。

### 分时轮询退避

- 单股基准 30s;连续 2 次失败退避至 60s;连续 5 次失败停止轮询并展示降级横幅。
- 用户主动切换股票时重置退避计数器。
- 多股关注(如持仓列表)时保留现有 `GET /quotes` 批量轮询;分时仅对当前选中股拉取。
