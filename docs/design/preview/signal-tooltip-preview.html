把鼠标移到图上带框的标记上(▼ 三只乌鸦 / ⚠ BOLL 收口)→ 出现解释浮层

实现口径(给开发看)

  • 前提:lightweight-charts 的 marker 是 series.setMarkers() 画在 canvas 上的, 没有 DOM 节点 → 原生 title / hover 都不生效,必须自己加一层。
  • 做法:用 chart.timeScale().timeToCoordinate(time) 拿 x, series.priceToCoordinate(high/low) 拿 y → 鼠标移动时做命中测试(半径约 ±34px / ±12px)→ 命中就显示 DOM 浮层。 图上原样式不动(标记仍由 canvas 画)。
  • 浮层位置:贴标记左边并排(水平留 ~14px 缝),绝不能压住标记本身 —— 压住了就等于把标记的悬停入口盖掉,点不到。 定位必须用标记自己的 rect,不能拿 canvas/svg 坐标推算: 标记按容器百分比摆、浮层按画布坐标系摆,两套坐标系对不上(本稿第一版就是这么错的)。
  • 浮层内容:标题(标记名 + 类型胶囊) → 这是什么 / 对股票走向的含义 / 要注意 三段 → 当前这只票的真实数据 → 底部固定免责小字。
  • 跟随:缩放/平移后要重算坐标 → 监听 timeScale().subscribeVisibleTimeRangeChange() 与 resize 重算;命中测试在 mousemove 里做,节流 60ms。
  • 词条:解释文案放前端 lib/glossary.ts(与 TermHint 共用同一份词典), 键 = 后端标记名,一字不差对表(BOLL 收口 / 三只乌鸦 …)。
  • 兜底:词条缺失时浮层只显示标记名 + 「暂无解释」,不猜、不编。
  • 键盘:标记不可聚焦(在 canvas 里)→ 右侧「形态识别」卡里每个形态名旁补一个 TermHint 的「?」,键盘用户也能查到同样的解释。
