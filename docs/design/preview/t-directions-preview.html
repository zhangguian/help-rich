做 T 方向判定 · 正T / 反T 两行对照

两个方向都写出来,并指出更适合哪一种。 反T = 先卖后买(高抛低吸)、正T = 先买后卖(低吸高抛)。 正T 的股数受账户可用资金约束 —— 没填资金就不给数字(不给 0,不给猜的数)。
下面每个场景都是真实接口 POST /api/calculator/review 的返回,数据取自 2026-10-24 盘中。

1推荐条 + 两行对照(核心形态)

推荐方向用青色描边 + 「更适合」标签;不适用的方向照常显示、灰显并写明原因(不隐藏)。

2缺资金时的形态

未填写可用资金时,正T 一行灰显 + 提示原因,并给出资金填写入口(琥珀色提示条)。 填了钱之后,正T 才会有股数上限 —— 见下方场景 E。

3正T 被推荐时的形态

实盘 5 只持仓里只有 002185 适合做 T,而它现价落在 T 区间 57% 位置 → 判定推荐的是反T, 真实数据里拿不到「正T 被推荐」的样本。下这一场景是派生示意: forward 一行的股数 / 金额 / 两步全部取自真实接口响应,只把推荐方向按规则改写,界面上标了「示意」。
