# 买股工具室 · 功能与交互总览

> 面向客户的非技术文档 · 当前版本 v0.4.2 · 更新日期 2026-08-02

---

## 一、产品概览

**买股工具室** 是面向小白股民的**买股看股辅助工具**:打开即用的盯盘工作台,把"这只股票现在什么情况、能不能买、该不该卖"用大白话讲清楚。

- **看涨跌**:自选 / 持仓一眼扫清,现价、涨跌、浮盈实时更新。
- **看 K 线**:日/周/月/60 分钟周期切换,均线 + 成交量副图。
- **AI 解读**:技术指标全部确定性计算,AI 只负责把指标翻译成白话——看多/看空/中性、关键价位、操作建议、风险提示。
- **提问助手**:不懂就问,"现在能买吗?""回调到什么价位算企稳?"AI 结合你的持仓成本回答。
- **真实数据**:行情、K 线、板块资金、快讯全部来自新浪财经公开数据源,零模拟数据;数据源不可用时优雅降级提示。
- **本地私有**:持仓、流水、设置全部保存在本地数据库。

## 二、功能点与交互方式

### 1. 盯盘工作台(首页 · `/`)

打开应用就是三区联动的工作台,无需进入任何子页面:

| 区域 | 内容 | 怎么用 |
| --- | --- | --- |
| **左侧盯盘** | 自选 + 持仓列表:现价 / 涨跌幅,持仓行带标记 | 点击任意一行 → 中间 K 线 + 右侧分析**整体联动切换**(不跳转页面) |
| **中间 K 线区** | 当前选中股票的 K 线图 + 成交量副图 | 顶部周期按钮切换 日K / 周K / 月K / 60分;顶部可切 板块资金 / 快讯 tab |
| **右侧上栏·操作提示** | AI 看多/看空/中性大徽章 + 5 张技术指标卡 + 支撑压力价位 + 企稳理由 | AI 不可用时自动降级为纯指标展示,页面永不空白;[🔄 重新分析] 可随时刷新 |
| **右侧下栏·AI 对话** | 单轮问答助手,结合持仓成本回答 | 输入问题回车即答,换股票自动清空上一轮 |

### 2. 盯盘列表操作

- **添加自选**:列表顶部 [+ 自选],输入代码 / 名称即入库。
- **一键清仓**:持仓行尾 🛑 按钮 → 弹窗自动填入实时卖出价 → 确认后自动生成卖出流水并结算实际盈亏。
- **持仓 tab**:只显示持仓股票;自选 tab 显示全部自选(持仓带标记)。

### 3. 顶部功能页(从首页顶 tab 进入)

| 页面 | 功能 | 怎么用 |
| --- | --- | --- |
| `/` · 板块资金 tab | 今日板块资金净流入排行 | 净额(亿)红涨绿跌,附领涨股;点击立即回盯盘 |
| `/` · 快讯 tab | 新浪 7×24 财经快讯流 | 自动刷新,点击立即回盯盘 |
| `/settings` | 设置 | LLM Provider 切换、API Key 配置、数据备份/恢复、截图识别 |

### 4. 历史工具(记账 / 报表向,已从工作台撤出,设置页底部进入)

> v0.4 起产品转型为"买股看股",以下记账向功能保留代码与数据,入口统一收编到设置页「🕰 历史工具」分区。

| 页面 | 功能 |
| --- | --- |
| `/transactions` | 流水录入(手动 / 截图识别 / JSON 粘贴)+ AI 诊断评分 |
| `/calculator` | 交易手续费、成本、收益计算 |
| `/annual-report/{年}` | 年度买卖汇总、收益统计 |
| `/risk-report` | 持仓集中度与风险敞口报告 |
| `/rebalance` | 智能调仓建议 |
| `/provider-stats` | AI 模型使用占比统计 |
| `/holdings-health` | 持仓健康度检查 |
| `/sector-fund-flow` | 板块资金排行 + 异动订阅(独立页) |

## 三、系统特性

- ✅ **零模拟数据**:所有数字来源于真实接口,行情不可用时降级提示。
- ✅ **AI 只翻译不计算**:指标由确定性算法计算,LLM 失败页面自动降级,绝不影响指标展示。
- ✅ **断网友好**:后端未启动、行情源不可用都不会导致页面崩溃,均有清晰提示。
- ✅ **数据私有**:持仓、流水、笔记全部本地存储,不上传第三方。
- ✅ **经过充分测试**:自动化测试 325 项全绿,关键路径端到端验证。
- ✅ **操作可逆**:删除持仓、清仓等关键操作均有确认弹窗,误操作可恢复(流水层完整留痕)。
