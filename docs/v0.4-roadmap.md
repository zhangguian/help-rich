# v0.4 Roadmap · 买股看股辅助工具转型(详细版)

**计划日期**:2026-08-02 · **定位变更**:从"投资记账辅助"→"小白股民买股看股操作辅助"
**界面风格**:Liquid Glass(液态玻璃)· 单主题纯黑 void · emerald 霓虹强调

---

## 一、背景与定位变化

v0.2/v0.3 定位为"投资记账 + 智能分析"。经复盘,记账向功能对小白价值有限,
小白股民最痛的核心诉求是:**看自选/持仓涨跌、分析 K 线、获得看多看空与操作建议**。

### 新定位

> 面向小白股民(没有技术分析经验、看 K 线如看天书)的买股看股辅助工具:
> 帮用户看清 自选/持仓股票 涨跌,把 K 线走势翻译成大白话(看多看空、
> 放量缩量、上涨/下降通道、企稳点),并对"现在能买吗 / 该不该卖"这类
> 操作提问给出参考建议。

### 核心原则

- **真实数据**:所有行情/K线来自新浪,零模拟,数据源不可用明确提示
- **AI 只翻译不计算**:涨跌结论、指标全部由代码精确计算,LLM 只做"人话翻译"
- **降级优先**:任何 AI 失败 → 自动退回纯指标/纯数据展示,页面永不空白
- **视觉气质**:premium · calm · AI-native · 高密度但不拥挤 · 弹性动效全程在场

## 三、UI 设计规范(Liquid Glass)

> 设计目标是:**画布纯黑,面板悬浮,emerald 霓虹作唯一强强调色,信息层级靠白字透明度,不靠大色块**。

### 3.1 Canvas(画布)

| Token | Value | Role |
| --- | --- | --- |
| `--void` | `#000000` | 页面画布(纯黑,不是深灰) |
| `--glow-emerald` | `rgba(16,185,129,0.08–0.18)` | 环境光(emerald 弥散) |
| `--glow-cyan` | `rgba(56,189,248,0.05–0.10)` | 辅光 |

### 3.2 Glass 材质(核心)

```css
/* .liquid-glass */
background:
  linear-gradient(165deg,
    rgba(255,255,255,0.09),
    rgba(255,255,255,0.03) 35%,
    rgba(255,255,255,0.04)
  ),
  rgba(12,16,28,0.28);
backdrop-filter: blur(var(--blur-liquid, 40px)) saturate(160%);
border-radius: 20–22px;
box-shadow:
  inset 0 0 0 1px rgba(255,255,255,0.06),
  inset 0 1px 0 rgba(255,255,255,0.18),   /* specular 顶缘高光 */
  0 18px 50px -12px rgba(0,0,0,0.65);
```

变体:`.liquid-glass-hover` / `.liquid-glass-active` / `.liquid-pill` /
`.liquid-btn-primary` / `.liquid-btn-ghost` / `.frost-card` /
`.frost-card-active`。

blur 强度:**默认 40px,可改 24/40/56**(用户设置项,本轮默认 40px)。

### 3.3 文字层级(opacity on white)

- `0.92` · 标题
- `0.68` · 正文
- `0.45` · 标签
- `0.32` · 元信息

### 3.4 Brand 色(强调色)

| 用途 | 色值 |
| --- | --- |
| Primary CTA | `#34d399 → #10b981 → #059669`,字色 `#04120c` |
| Danger(跌/止损/错误) | `#f43f5e` |
| Warn(警示) | `#fbbf24` |
| Up(红涨,中国惯例) | `#dc2626` |
| Down(绿跌,中国惯例) | `#16a34a` |
| Status dots | emerald pulse = 进行中 |

**色系冲突控制**:`--down` 绿与 `--glow-emerald` 都偏绿。策略:
- emerald 仅用于**交互强调**(按钮 / 选中态 / 徽章 / 状态点);
- `--down` 用于**行情语义**(K线/涨跌幅/盈亏),色值降饱和度拉开距离
- 工作台空闲处才显现 emerald 环境光,不与行情色块贴脸

### 3.5 字体

- **UI**:`Plus Jakarta Sans` + 中文系统字体(本地自托管 woff2,无外网)
- **Mono**:`JetBrains Mono`(任务 ID、时间、百分比、价位)
- 仪表盘 chrome 11–13px;KPI 数字 26–28px;页面标题 20–22px

### 3.6 动效铁律表(原版)

| 场景 | 必须动效 |
| --- | --- |
| 侧栏切换 8 大页面 | 左右方向滑入 + blur + 轻微缩放(`RouteTransition`) |
| 顶栏标题 | 交叉淡入(`TitleTransition`) |
| 日/周/月、设置 Tab、总览 Tab、分析周期 | 横向滑动 + blur(`ViewTransition`,带 direction) |
| 消息通知 / 站内信 / 所有二级弹窗 | 遮罩淡入 blur + 面板 spring 缩放上浮 + 内容错落入场(`LiquidModal`) |
| 筛选 pill / 视图 pill | `layoutId` 滑块 |
| 列表展开、选中、Hover | 高度动画 / 左边条 / `whileHover` `whileTap` |
| CoverFlow | spring 位姿 + 滚轮切换 |
| 完成任务 / 创建 | confetti(可设置关闭) |

**铁律**:任何「点了有反馈」的控件,禁止瞬切无动画。`AnimatePresence` 的直接子节点必须是带 `key` 的 `motion.*`,否则 exit 无效。

### 3.7 动效铁律·股票场景映射

| 场景 | 动效 |
| --- | --- |
| 顶部 tab 切换(自选/持仓/板块/快讯/设置) | `ViewTransition` 横向滑动 + blur(方向感知) |
| K线周期切换(日/周/月/60分) | `ViewTransition` 横向滑动 + blur |
| 自选/持仓切换 | `ViewTransition` |
| 选中自选/持仓行 | `layoutId` 滑块 + 左边条 |
| 切换选中股票(中间+右侧联动) | spring 位姿(轻量 CoverFlow 替代) |
| 添加/清仓/确认入库/输入 API Key 等弹窗 | `LiquidModal`(遮罩 blur + spring 缩放 + 错落入场) |
| AI 分析/回复内容 | 错落入场(`stagger`) |
| 列表项 Hover/Tap | `whileHover` / `whileTap` |
| 板块异动提醒 toast | spring 上浮 + emerald pulse |
| 持仓添加成功/清仓完成/截图入库成功 | confetti(可在设置中关闭) |
| 标题区 | `TitleTransition` 交叉淡入 |
| 跳转设置页等主区切换 | `RouteTransition` 左右滑入 + blur + 缩放 |
| 周期/排序/筛选 pill | `layoutId` 滑块 |

### 3.8 Layout 框架

```
.app-frame:  clamp(176px,14vw,280px) | 1fr ; padding clamp 流体 ; max-width: none
.tasks-frame: minmax(0,1fr) | clamp(260px,24vw,400px) ; stretch ; height 100%
.tasks-left:  column ; 盯盘列表 flex-1 ; 操作入口 mt-auto 贴底
.board-deck-row: minmax(280px,1.05fr) | minmax(240px,1fr)
.tasks-right: 通高,详情 flex,footer mt-auto 贴底
≥1600: 侧栏/详情再放宽,主区继续吃满剩余宽度
```

- 左右必须随视口自适应,禁止写死 1600 居中
- 空白 void 在组件内部,不是靠砍掉整页左右边距
- 断点:1280 详情下沉;1100 看板/堆叠;900 侧栏改顶置
- 工具条、筛选、视图切换:单行 nowrap,可横向微滚

### 3.9 Do / Don't

**Do**
- 纯黑 + 透玻璃 + 环境光
- 框架 padding、底对齐、单行工具条
- 任何切换都有动效
- 弹窗统一 LiquidModal
- 选中/聚焦高亮用 emerald

**Don't**
- 实心灰块、厚描边、彩虹强调色
- 顶栏下拉硬撑布局
- 瞬切无动画
- 面板互相遮挡、底部莫名细线
- 死按钮、半成品二级页
- 原生 `<select>`(统一 LiquidSelect)
- 实心 navy 卡片(规范明令)

### 功能 1 · 左侧盯盘 aside(自选 + 持仓涨跌列表)

**功能说明**:左侧固定宽度 aside,展示自选股(含持仓股)盯盘列表,每行:
股票名称、代码、现价、涨跌幅(红涨绿跌)。持仓行额外显示 今日盈亏、浮动盈亏。
选中行有 emerald 左边条高亮(layoutId 滑块)。

**使用情景**:

- 早上 9:40 打开工作台,一眼扫完"今天自选里谁红了谁绿了,我买的茅台现在什么情况"
- 盘中快速知道持仓是否触发止损线
- 不用记代码,点击任何一行 → 中间 K线 + 右侧面板自动换股,即时开始分析

**交互方式**:

- 顶部提供「➕ 添加自选」按钮(弹 `LiquidModal`,输入代码/名称)
- 持仓行尾「🛑 清仓」按钮(沿用 v0.3 一键清仓弹窗,改 `LiquidModal`)
- 后端/行情不可用 → 行内显示 "--" + 顶部黄色降级横幅
- 选中切换:`layoutId` 滑块动画 + 左边条渐入;Hover 时 `whileHover` 微缩放
- 长列表滚动:aside 内部独立滚动,不互相遮挡

**实现要点**:

- 复用 watchlist/positions API + `/api/quotes` 批量行情
- 涨跌幅按现价 vs 昨收计算,后端统一返回,前端只渲染
- 选中态用 `framer-motion` `layoutId` + `motion.li`

### 功能 2 · 中间 K线区

**功能说明**:工作台中部核心区,显示当前选中股票的 K 线图(主图 + 成交量副图),
顶部行情头部,周期切换按钮(日/周/月/60分),十字光标联动显示 OHLC 与成交量。

**使用情景**:

- 选中股票后第一件事看 K 线走势,验证"涨/跌/横盘"
- 切周K/月K 看大趋势,切 60 分K 看日内节奏
- 十字光标确认某日 OHLC 与成交量,验证"放量突破"等说法

**交互方式**:

- 顶部行情头部:名称 / 代码 / 现价 / 涨跌幅 / 成交量(数据降级显 "--")
- 周期按钮组:日K/周K/月K/60分 → `ViewTransition` 横向滑动 + blur,切周期自动重拉
- K线主图:lightweight-charts,红涨绿跌(中国惯例)
- 成交量副图:`addHistogramSeries`,与 K 线同色
- 十字光标:同时显示 OHLC + 成交量

**实现要点**:

- 增强 `KLineChart.tsx`,props 扩展 `{stockCode, period, showVolume}`,向后兼容
- 周期切换重新拉 `/api/kline/{code}?period=...`,loading 用 Glass skeleton

### 功能 3 · 右侧上栏 · 操作提示(技术指标 + AI 结论)

**功能说明**:右侧面板上半部分,自上而下:
① AI 分析卡(看多/看空大徽章 + 白话结论) ② 关键价位 chips(企稳/支撑/压力)
③ 技术指标面板(5 张指标卡:均线 / 量比 / 通道 / 支撑压力 / 企稳点)
④ 「🔄 重新分析」按钮。

**使用情景**:

- 看不懂 K 线的用户直接看结论:"上涨通道 + 放量 + 站上企稳点 = 强势"
- 买入决策前看 AI 看多/看空 + 关键价位,做参考
- 持有中定期看走势有没有变坏(通道是否破坏、量能是否异常)

**交互方式**:

- AI 徽章:看多(red pulse)/看空(green pulse)/中性(灰),emerald 仅在"进行中"状态点用
- 指标卡:结论徽章 + 白话解释 + 价位 chips(可复制)
- 失败降级:AI 不可用 → 显示"以下为纯技术指标",自动隐藏 AI 卡
- 「🔄 重新分析」点击 → spring loading + 重新请求

**实现要点**:

- AI 结论走 `/api/stock/{code}/analysis`(LLM 失败自动降级)
- 5 个技术指标全部确定性计算(代码级),不走 LLM
- 面板内容错落入场(`AnimatePresence` + `stagger`)

### 功能 4 · 右侧下栏 · AI 对话助手("问一问")

**功能说明**:右侧面板下半部分,对话式问答入口。用户用大白话提问,
系统结合**实时行情 + 技术指标 + 用户持仓成本**给出参考回答。
回答末尾附数据出处,用户可点指标面板自己核对。

**使用情景**(典型提问):

- "我 60 块的成本,现在 52,该止损还是补仓?"→ 结合成本 + 支撑位回答
- "现在这个位置还能上车吗?"→ 结合企稳点/通道/量能
- "放量上涨是什么意思?我是该追还是等?"→ 结合量比指标解释
- "AI 看多但我的成本高,要不要先减一半?"→ 结合成本 + AI 结论

**交互方式**:

- 底部固定输入框 + 发送按钮,emerald 渐变 CTA
- 消息气泡式对话,保留最近若干条会话在内存
- 加载中显示"AI 思考中…"(emerald pulse 状态点)
- 回答错落入场,关键价位以 chips 嵌入消息体
- 失败提示重试,无响应时不留空(给出降级提示)

**实现要点**:

- `POST /api/stock/{code}/chat`,body `{question}`,持仓成本从 positions 表自动取
- 上下文固定喂入:最新行情 + 指标摘要 + 持仓成本(有则带)
- 本轮只做单轮问答,不做多轮记忆(明确范围,避免复杂度失控)
- 面板可独立滚动,不影响右侧上栏指标卡

### 阶段 1 · 技术指标层(纯函数,可单测)
`backend/app/services/ta_service.py` — 输入日K,确定性输出:

- 均线 MA5/10/20/60(序列 + 最近值)
- 量比 = 近5日均量 / 前20日均量(≥1.5 放量,≤0.7 缩量)
- 通道判定:近 N 日价格回归斜率 → 上涨/下降/震荡通道 + 上下轨价位
- 支撑/压力:近期高低点 + MA20/MA60
- 企稳检测:站上 MA20 + 缩量回踩不破前低 + 放量突破 → 输出企稳价位

## 九、决策记录

| 决策 | 选项 | 理由 |
| --- | --- | --- |
| 主题策略 | **纯黑单主题**(砍双主题) | 规范明令"画布必须是纯黑 void",双主题浅色态与规范冲突,砍双主题实现最贴合 |
| 强调色 vs 语义色 | **emerald 仅作交互强调,涨跌红绿保留语义** | 中国股市红涨绿跌不可替换;emerald 与语义绿冲突时,色相/饱和度/使用场景三维度分离 |
| 个股详情交互 | **工作台单页联动**(删除独立路由) | 用户描述明确"点击…中间区域显示 K线",非路由跳转;减少页面切换,更聚焦盯盘体验 |
| 板块资金/快讯入口 | **收编为顶 tab**(不保留独立页) | 与"四区工作台"布局一致,减少入口跳转;原独立路由保留兼容(从设置/历史工具可达) |
| AI 问答记忆 | **只做单轮,不做多轮** | 范围清晰,降低复杂度;多轮记忆延迟作为后续 v0.4+ 锦上添花 |
