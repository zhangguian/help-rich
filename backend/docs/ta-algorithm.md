# 技术指标算法文档(改造后规格 v2)

**代码位置**:`backend/app/services/ta_service.py`(纯函数,确定性计算)
**输入**:升序日K列表 `[{date, open, high, low, close, volume}, ...]`
**设计原则**:确定性、无 LLM 参与数值计算;数据不足返回 `None`/空并记录降级原因,不抛异常(空输入抛 `TaError`);模块间引用走全精度,仅接口输出四舍五入。
**输出**:`{latest_close, ma, ma_series, volume, channel, support_pressure, stabilize, data_quality}`
**下游**:指标 JSON + 最近 30 根 K 线摘要 → LLM 白话解读(仅文字解读)。

---

## 0. 数据预处理约束(前置契约)

三条显式前置契约,数据源侧保证,本服务不做数据清洗:

1. **复权方式**:全链路统一使用**前复权**数据;MA60 / 通道的 60 根窗口内若发生除权除息,不复权数据会出现价格跳变,导致 MA、回归斜率、σ 全部失真
2. **缺失处理**:停牌日直接**跳过**(不填充);通道回归的 x 为 K 线索引而非日历日,复牌后的价格跳变(如补跌)会扭曲回归斜率,属已知特性
3. **排序方向**:严格按交易日期**正序**(旧→新)排列,`[-1]` 取最新

---

## 1. 均线 MA(SMA)

**算法**:简单移动平均,滚动窗口累加:

```
S_{n-1} = Σ_{j=0}^{n-1} v_j(直接求和初始化)
S_i = S_{i-1} + v_i - v_{i-n}   (i ≥ n 才走递推)
MA_n[i] = S_i / n               (i ≥ n-1,否则 None)
```

- 初始条件说明:`S_{n-1}` 由前 n 根直接求和得到,i < n 时**不使用负索引**递推(避免 Python 负索引静默取到序列尾部元素)
- 输出 MA5 / MA10 / MA20 / MA60 各取最新值 + `ma_series`(最近 60 根供前端画线)
- **精度约束**:`_sma` 内部**保留全精度**,下游模块(支撑压力、企稳)引用未舍入的 MA20/60;仅在接口输出和 `ma_series` 时 `round(x, 2)`,消除贴边判定翻转

---

## 2. 量比(Volume Ratio)

**算法**:

```
量比 = 近5日均量 ÷ 再前20日均量 = mean(volumes[-5:]) / mean(volumes[-25:-5])
```

- 需 `len ≥ 26`;前 20 日均量 ≤ 0 → `None`
- 阈值:`≥1.5` expand / `≤0.7` shrink / 中间 normal
  - **非对称说明**:0.7 并非 1.5 的精确倒数(严格对称应为 ≈0.667),系有意设计——放量需偏离 +50% 才确认(严),缩量仅需偏离 -30%(松),缩量端有意放宽
- **语义声明**:本字段实为"5 日 / 25 日量能趋势比",反映量能扩张/收缩周期,非传统"当日量比";前端以"量能"中性文案展示,不作"今日放量"解读
- 传统当日量比口径(末日 ÷ 前5日均)列为**单独立项**

## 3. 通道状态(Channel)

**步骤**:
1. 取最近 60 根收盘价;不足 10 根 → `sideways`(slope/upper/lower=None),记录降级
2. **线性回归斜率**(最小二乘):

```
slope = Σ(xᵢ-x̄)(yᵢ-ȳ) / Σ(xᵢ-x̄)²    (x=0..n-1,y=收盘价)
```

3. **归一化**:`slope_norm = slope / 均价`
4. **状态判定**(固定阈值):`> +0.0015` → up;`< -0.0015` → down;中间 → sideways
   - 阈值自适应(波动率分层/分位数)列为**单独立项**
5. **上下轨**:回归末点 `y0 = slope×(n-1) + (ȳ - slope×x̄)`,带宽用**残差标准差**:

```
σ_res = sqrt( Σ(yᵢ - ŷᵢ)² / (n-2) )   ŷᵢ = slope×xᵢ + (ȳ - slope×x̄)
upper = y0 + 1×σ_res
lower = y0 - 1×σ_res
```

   - 修复动机:原 `σ_full` 含趋势分量(`σ_full² = σ_res² + slope²·σ_x²`),趋势越强轨道越宽,突破信号区分度越低;残差 σ 使轨带围绕回归线对称、趋势行情中收窄
   - **σ_res = 0 边界**(完美直线):upper = lower = y0,通道带宽为零,几何上价格完美贴合回归线;状态判定不受影响,正常按 slope_norm 判向(状态判定与 σ 无关,带宽为加减法亦无除零;仅当未来引入带宽归一化 `σ_res/均价` 时需在此处防除零)
   - 带宽 1σ(正态覆盖 ~68%):当前仅展示 + 喂 LLM,非信号触发;若未来做突破信号,需升至 1.5–2σ 另议
6. 输出 `{state, slope, upper, lower, resid_std}`(resid_std 新增)

## 4. 支撑 / 压力(Support / Pressure)

**取数**:
- 近 20 根低点 `lo20 = min(lows[-20:])`(含当日,数据不足 20 根时取全部)、**全期最低** `lo_all = min(lows)`、MA20、MA60
- 高点同理:`hi20 = max(highs[-20:])`、`hi_all = max(highs)`
- 修复动机:原 `max(20, len-5)` 在数据 >25 根时窗口线性膨胀(200 根时取近 195 根),与全期低点重叠,丢失"近 20 日局部低点"档位
- 候选构建阶段**显式剔除 None**(MA 不足时),不依赖 `> 0` 隐式过滤

**档位合成**:
- 支撑 = 候选(MA20、MA60、lo20、lo_all)中 ≤ 现价 者
- 压力 = 候选(MA20、MA60、hi20、hi_all)中 ≥ 现价 者
- 现价恰等于候选价时**归入支撑**(偏保守)
- **容差去重**:排序后与已保留档位差值 < **0.5%** → 跳过(合并"MA20=101.35 与低点=101.34"这类伪独立档,保留先出现者)
  - **已知局限**:贪心归并不传递——候选 A=100.0 合并 B=100.3,但 C=100.6 与 A 差 0.6% 超容差被保留,而 C 与已跳过的 B 仅差 0.3% 本应合并。对最多 3 档输出影响极小,若需严格可改聚类归并
- 各输出最多 3 档,不分强弱层级(层级化列为后续优化)

---

## 5. 企稳检测(Stabilize)

三段条件**同时满足**(AND)判定企稳:

1. **站上 MA20**:`现价 > MA20`(全精度比较)
2. **回踩不破前低**:`min(lows[-5:]) > min(lows[-25:-5])`(近 5 根含当日 vs 前 20 根不含当日,窗口不重叠故有意义;需 ≥26 根,不足取 `min(lows[:-1])`)
3. **放量突破**:`volumes[-1] > 1.3 × mean(volumes[-6:-1])`(原 1.0 倍约 40-50% 日度满足率,无筛选力;1.3 倍为保守值,待回测联合通过率后可调至 1.5)

**企稳价位**:`max(MA20, 前低)`——已证无矛盾:条件 B 成立时现价 ≥ 近5日最低 > 前低 = 企稳价位;条件 A 成立时现价 > MA20 = 企稳价位。

**保留 AND 不放宽**(设计决策):条件 A/B 各有筛选力,AND 交集整体压假阳;OR 放宽引入噪声,待回测后评估。

每项输出 `reasons[{name, ok, note}]` 供前端逐条展示。

---

## 6. 降级状态透明化

`data_quality`:

```
{ kline_count: 当前K线根数, degraded: ["channel: len<10", "stabilize: ma20=None", ...] }
```

- 每模块降级原因结构化记录,前端可提示"数据不足",后端可排查
- 结构新增字段,前端不消费,无破坏
