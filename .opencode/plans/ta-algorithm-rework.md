# 技术指标算法改造(整合外部评审 v3)

来源:ta_service.py 算法评审(两轮外部评审 + 我方交叉验证)。六处核心修复已确认正确(lo20 窗口、残差 σ、MA 精度、容差去重、放量阈值、降级透明化)。
本版补齐第二轮评审的三处规格缺陷 + 两处增量建议。

## A. 文档修正(backend/docs/ta-algorithm.md)

### A1. MA 递推初始值补全(评审:规格完整性问题)
- `_sma` 节补声明:`S_{n-1} = Σ_{j=0}^{n-1} v_j`(直接求和初始化),仅 `i ≥ n` 走递推 `S_i = S_{i-1} + v_i - v_{i-n}`
- 显式说明:i < n 不使用负索引(避免 Python 负索引静默取尾部元素)——当前实现从 i=0 累加本就无负索引,属文档补全,实现不变

### A2. σ_res=0 描述修正(评审:与计算路径不符)
- 现状文档写"按 slope 符号直接判 up/down,避免除零"——错误:状态判定走 `slope_norm = slope/均价`(与 σ 无关);带宽 `y0 ± σ_res` 是加减法,无除法,不存在除零
- **改写为**:"σ_res=0(完美直线):upper = lower = y0,通道带宽为零;状态判定不受影响,正常按 slope_norm 判向。若未来引入带宽归一化(σ_res/均价)需在此处防除零"
- 实现侧:不加特殊分支,保留自然结果

### A3. 数据预处理约束正文显式化(评审:正文缺位)
- 第 0 节重构为三条显式前置契约,每条独立:
  1. **复权方式**:全链路统一前复权(窗口内除权除息导致 MA/slope/σ 失真)
  2. **缺失处理**:停牌日跳过(通道 x = K 线索引非日历日;复牌跳变扭曲斜率属已知特性)
  3. **排序方向**:严格正序(旧→新),`[-1]` 取最新

### A4. 量比阈值说明补充(评审:0.7 非 1.5 精确倒数)
- 标注:0.7 为非对称阈值,缩量端比严格对称值(1/1.5≈0.667)放宽——"放量严(+50%)、缩量松(-30%)"系有意设计,防维护者对称性疑问

### A5. 容差去重局限标注(评审:贪心链式不传递)
- 标注已知局限:贪心归并不传递(候选 A=100.0 合并 B=100.3,但 C=100.6 与 A 差 0.6% 被保留,而 C 本应与 B 合并);对 ≤3 档输出影响极小,若需严格改聚类归并

## B. 实现计划(backend/app/services/ta_service.py,批次 1+2)

### B1. lo20/hi20 窗口修复(`_support_pressure`)
- `max(20, len-5)` → `lows[-20:]`/`highs[-20:]`;`lo60`→`lo_all`;候选显式剔除 None;现价恰等候选价归入支撑

### B2. 通道残差 σ(`_channel`)
- `σ_res = sqrt(Σ(yᵢ-ŷᵢ)²/(n-2))`;upper/lower = y0 ± σ_res;输出加 `resid_std`;**不加 σ=0 特殊分支**(见 A2)

### B3. MA 精度传递(`_sma`)
- 内部不 round,输出时 round(2);`_sma` 累加实现不变(无负索引,见 A1)

### B4. 支撑压力容差去重
- 排序后与已保留档差 <0.5% 跳过;已知局限见 A5

### B5. 企稳放量阈值(`_stabilize`)
- `vol[-1] > 1.3 × mean(vol[-6:-1])`;AND 保留

### B6. data_quality 降级透明化(扩展覆盖,评审增量)
- `compute_indicators` 输出加 `data_quality: {kline_count, degraded: [...]}`
- **系统化覆盖 MA 降级**:len<5/10/20/60 分别记录 `ma5: len<5` 等
- **企稳退化显式化**:len<26 → `stabilize: len<26`;MA20=None → `stabilize: ma20=None`(不再靠不等式静默拦截)
- 通道 len<10 → `channel: len<10`
