## 第一章 设计原则

> **基调**:Linear / Notion 风格的中性灰 + 数据优先 + 克制使用强调色 + 降低决策疲劳

### 1.1 核心原则

| # | 原则 | 落地表现 |
|---|---|---|
| P1 | **数据优先** | 数字大于文字,数字用等宽字体 |
| P2 | **一个页面一个任务** | 计算器只算成本、流水只录流水,不堆叠功能 |
| P3 | **即时反馈** | 输入即计算,提交即推送,延迟不超过 1s |
| P4 | **降低决策疲劳** | 评分卡 / 盈亏表帮用户做减法,不堆数据 |
| P5 | **合规意识** | 任何"建议"型内容附"不构成投资建议"水印 |
| P6 | **专业克制** | 不用 emoji 装饰,不用渐变光效,卡片阴影细腻 |

### 1.2 反原则(避免)

- ❌ 不用 Tailwind 默认紫色作为主色(同质化)
- ❌ 不用大色块对比(类 Robinhood 风格),只用中性灰 + 单点强调色
- ❌ 不堆动效——只用必要的过渡(200~300ms)
- ❌ 不堆统计图表——1 个页面最多 1 个主图表

## 第三章 信息架构

### 3.1 整体导航

```
┌────────────────────────────────────────────────────────┐
│ Logo  盘后诊股室                                        │
├────────────────────────────────────────────────────────┤
│ ⌂  首页(持仓概览)                                       │
│ ✏  流水录入        [主操作]                             │
│ ⊕  成本计算器      [主操作]                              │
│ ★  自选股(v0.2)                                       │
│ ⚙  设置                                                │
└────────────────────────────────────────────────────────┘
```

- **3 个核心入口在左侧固定**
- 计算器与流水录入是 P0 高频功能,**置顶**
- 设置收起在底部

### 3.2 页面-模块关系

```
首页(持仓概览)
  ├─ 持仓列表(读)
  ├─ 入口 → 流水录入(写)
  ├─ 入口 → 成本计算器(算)
  └─ 入口 → 单条持仓详情(成本/盈亏明细)

流水录入
  ├─ 录入表单
  ├─ 流水列表(含评分)
  └─ 评分详情弹窗

成本计算器
  ├─ 股票选择
  ├─ 当前持仓区(读)
  ├─ 预交易参数(写)
  └─ 实时结果区(算 + 21 档表)
```

### 5.3 PnlHeatmap(21 档)详细设计(v1.5 重设计)

**v1.5 改进**:用户场景"我持仓亏了 5%,接下来怎么走?"——重点是**当前位置 + 未来路径**,不是 21 档浏览。

**核心设计元素**:
1. **当前价标线**(必选):垂直 dashed line,标记当前市价所在档位
2. **未来路径预测**(5 档前向虚线):从当前价延伸 "+5%/0/-5%" 三个方向
3. **加仓区间高亮**:建议买入/卖出区间用浅色背景
4. **数字字号放大**(从 14px → 24px):关键数字一眼可见
5. **移动端折叠**:21 档 → 5 档关键位置(±5%/±2%/0)

**ASCII 示意(最终落地形态)**:

```
                  ┃ ← 当前价标线(dashed)
                  ┃
 -10% ━━━━━━━━━━━━┃━━━━━━━━━━━━━━━ +10%
       红色       ┃  绿色
   (亏损)         ┃(盈利)
                  ┃
        ▲▲▲ 加仓区间 ▲▲▲
        (浅蓝/浅红背景)
        
  hover 时:
  ▍▍▍▍▍▍▍▍▌▌▌▌▌▍▍▍▍▍▍▍▍▍▍▍▍
           ↑↑↑
         放大 1.2x
         其他 opacity 0.5
```

**数据**:21 档 (-10% ~ +10%,步长 1%)
**字段**:pct, price, market_value, pnl
**排序**:按 pct 升序(左 = -10%,右 = +10%)
**颜色**:
- pnl < 0:status-up(红)
- pnl > 0:status-down(绿)
- pnl = 0:status-neutral(灰)
**宽度**:每个柱 = 盈亏金额绝对值的比例(归一化到最长柱)
**交互**:
- hover:显示 tooltip {pct, price, market_value, pnl}
- click:展开"假设买入 X 股的成本"
- 移动端:折叠为 5 档(±5%/±2%/0),其余折叠

**替代方案讨论**(v1.5 评审):
- 试过"单一数字 + 趋势线"(类似天气预报),但 21 档视觉冲击更强
- 采用当前方案,但**当前价标线 + 未来路径**必须显眼

## 第十章 动效与微交互(v1.2 新增)

### 10.1 动效原则

| 项 | 规范 |
|---|---|
| 时长 | 150ms(微)/ 250ms(小)/ 400ms(中)/ 600ms(大) |
| 缓动 | `ease-out`(默认)/ `cubic-bezier(0.4, 0, 0.2, 1)`(Material 标准) |
| 并发动效 | 不超过 2 个元素同时动画 |
| 减少动效 | `@media (prefers-reduced-motion: reduce)` 关闭所有非必要动效 |

### 10.2 8 个核心场景微交互

| # | 场景 | 动效细节 |
|---|---|---|
| 1 | 录入提交成功 | ✓ 飞入,持续 600ms;Toast 200ms 滑入 |
| 2 | 评分弹出 | 从 0 滚动到目标分数,1000ms ease-out |
| 3 | 数字变化(实时价) | Ticker 数字滚动(类股票报价),400ms |
| 4 | 21 档悬停 | 该柱放大 1.2x,其他柱 opacity → 0.5,150ms |
| 5 | 主题切换 | 圆环扩散过渡(circle-wipe),300ms |
| 6 | Toast 进入 | 右上滑入 + fade,200ms;退出 slide-out 150ms |
| 7 | 弹窗打开 | 缩放 0.95→1 + fade,250ms;遮罩 fade 200ms |
| 8 | 加载占位 | 骨架屏 shimmer 效果,1500ms 循环 |

### 10.3 减动效(可访问性)

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

## 第十二章 品牌声音与文案指南(v1.2 新增)

### 12.1 品牌定位

> **"克制的私人顾问"**

- 不用 emoji,不用感叹号,不用"快来试试"
- 不冷漠,该提示的提示,该警告的警告
- 用"数字 + 短句"代替"形容词 + 长句"

### 12.2 5 条语气规则

| # | 规则 | 反例 | 正例 |
|---|---|---|---|
| 1 | 用陈述句,不用感叹句 | 录入成功! | 已记录,正在分析 |
| 2 | 用数据,不用形容词 | 网络好像不太好 | 网络似乎不太给力 |
| 3 | 用动作,不用情绪 | 糟糕,失败了 | 重新加载试试 |
| 4 | 用"先 X 后 Y",不用"但是" | 评分失败,但是可参考 | 先看分数,评语稍后补 |
| 5 | 用"试试",不用"必须" | 你必须刷新 | 刷新试试 |

### 12.3 文案改进示例(v1.2 统一)

| 场景 | 原文案 | 改进文案 |
|---|---|---|
| 网络错误 | 请检查网络后重试 | 网络似乎不太给力,刷新试试 |
| AI 失败 | AI 评语暂时不可用 | AI 评语没出来,先看看分数吧 |
| 录入成功 | 已录入,诊断中 | 已记录,正在分析这次操作 |
| 卖出超额 | 卖出股数超过持仓 | 这只票只剩 X 股了,卖不出 Y 股 |
| 代码错误 | 股票代码不存在 | 找不到这只股票,核对一下代码? |
| 价格异常 | 价格不合理 | 价格似乎有问题,核对一下? |
| 持仓首笔 | 第一笔为建仓,成本 = 买入价 | 这是你的第一笔,成本就是买入价 |
| 评分延迟 | 诊断中 | 正在分析这次操作(预计 5~30 秒) |
| 持仓外买入 | 是否加入自选股? | 不在你的自选股中,加进来持续观察? |

### 12.4 禁用清单

- ❌ emoji 装饰(违反 P6)
- ❌ 感叹号(违反语气规则 1)
- ❌ 营销话术("重磅推出""限时特惠")
- ❌ 模糊量词("一些""少量""很多")
- ❌ 技术术语暴露给用户(用户不关心 422 / 500 / SSE)

> **盲点**:v1.3 把隐私做成"水印",是防御姿态。对个人自用工具,**"你的数据只有你能看"本身就是最大卖点**——商业工具做不到,这个工具天然就有。

#### 13.5.1 品牌定位升级

- 旧:合规水印("数据不上传任何第三方")
- 新:**隐私承诺 = 差异化卖点**,出现在每个用户可能犹豫"要不要信这个工具"的时刻

#### 13.5.2 五个触点

**触点 1:全局底部水印**(保留,已有)
```
🔒 仅本地存储,数据不上传任何第三方
```

**触点 2:评分详情弹窗 AI 评语末尾**(保留,已有)
```
以上仅为 AI 评语,不构成投资建议。评语生成时仅使用了股票代码与交易摘要。
```
- v1.6 增强:点击"交易摘要"四个字展开 tooltip,列出**实际传给 LLM 的全部 5 项脱敏字段**:
  ```
  传给 AI 的内容(脱敏后):
  ✓ 股票代码(如 000001)    ✓ 买入/卖出方向
  ✓ 股数区间(如 500-1000)  ✓ 交易日期
  ✓ 持仓占比
  ✗ 不传:价格、金额、持仓成本、身份证、任何个人信息
  ```
- 理由:把"脱敏"从口号变成**可核验的事实**,这是信任的根基

**触点 3:设置页"关于"区数据流向图**(v1.6 增强,已有文字版 → 加流向图)
```
┌──────────┐     ┌────────────┐     ┌─────────┐

**触点 4:首次启动欢迎页**(保留,已有,v1.6 加"数据可携带"承诺):
```
欢迎使用盘后诊股室

这是一个只属于你的工具:

[开始使用]

- 设置页"数据"分组导出按钮**置顶显示**

### 13.6.1 Key 管理交互细节(v2.1 新增)

#### 13.6.1.1 Key 输入框交互

| 元素 | 行为 |
|---|---|
| 默认状态 | password input(`type="password"`),显示 `***` 遮罩 |
| 眼睛图标 👁 | 点击后**临时显示 3 秒**(之后自动遮罩) |
| 输入新 Key | 清空旧值,显示 placeholder "输入新 Key..." |
| [✏] 编辑按钮 | 把"已配置"状态切回输入态 |
| [保存] 后 | 前端**立即清空输入框**(防 DevTools 泄露) |

#### 13.6.1.2 测试连接按钮

- **触发**:点 [测试] → POST /api/llm/test `{provider: "deepseek"}`
- **后端动作**:ProviderFactory.get("deepseek") → chat("回复 OK")
- **结果反馈**:
  | 场景 | UI |
  |---|---|
  | 成功(200) | ✓ 1.5s 后变回灰色 + Toast "连接正常" |
  | 401 无效 | ✗ 红色 + "Key 无效,请核对" |
  | 403 权限不足 | ✗ 红色 + "Key 权限不足,需启用 chat 权限" |
  | 超时 | ✗ 红色 + "连接超时,网络可能不稳" |
  | 500 错误 | ✗ 红色 + "服务异常,请重试" |

#### 13.6.1.3 安全设计

- **Key 输入时密码遮罩**,明文不显示
- **不提供复制按钮**(避免误复制到剪贴板)
- **提交后立即清空输入框**,防止浏览器历史 / DevTools 泄露
- **前端从不接收明文 Key**(GET /api/llm/keys 只返回 `{provider: configured: true/false}`,不返回 Key 内容)

#### 13.6.1.4 隐私承诺

卡片底部小字(沿用 §13.5 隐私品牌):
> Key 仅本地加密存储,不上传任何第三方
> 缺 Key 时诊断评分会提示"暂不可用"
